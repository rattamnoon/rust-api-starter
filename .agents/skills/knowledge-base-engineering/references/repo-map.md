# Knowledge Base Repo Map

Use these files as the source of truth for repository knowledge:

- `docs/README.md`: KB entry point and update rules
- `docs/architecture/system-overview.md`: high-level service boundaries and main responsibilities
- `docs/architecture/module-map.md`: module ownership and code structure
- `docs/architecture/data-flow.md`: request, auth, persistence, and operational flows
- `docs/adr/README.md`: architecture decision index
- `docs/bugs/README.md`: bug record index
- `docs/incidents/README.md`: incident record index
- `docs/changes/README.md`: behavior-change history
- `docs/runbooks/README.md`: operational procedures

Use `docs/templates/*.md` instead of inventing a new document shape.
